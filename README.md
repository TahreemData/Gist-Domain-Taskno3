# GIST-Domain-Taskno2 - Retail Sales Analysis Dashboard

## 📊 Overview
This project is part of GIST Domain Task 2. The goal was to analyze retail sales data and create an interactive dashboard to visualize key business metrics.

The dashboard provides insights into sales performance, order status, payment methods, and referral sources.

##  Key KPIs (Key Performance Indicators)
The dashboard tracks the following metrics:
- **Total Price:** 12,647,431.90
- **Total Orders:** 1,100
- **Total Quantity:** 2,519
- **Average Total:** 7,204
- **Average Unit:** 156

##  Visualizations Included
1.  **Sales By Order Status:** Bar chart showing sales distribution across different order statuses.
2.  **Order Count By Order Status:** Horizontal bar chart for number of orders in each status.
3.  **Order By Referral Source:** Pie chart showing which channel brings the most orders.
4.  **Sales By Payment Method:** Pie chart breaking down sales by payment type.
5.  **Sales Trend:** Line chart showing sales trend over time.
6.  **Orders By Referral Source:** Bar chart for order volume by source.

##  Tools & Technologies Used
- **Microsoft Excel:** For data cleaning, analysis, and dashboard creation
- **Pivot Tables & Pivot Charts**
- **Slicers for Interactivity**
